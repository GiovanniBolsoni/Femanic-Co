# Changelog

## 2.1.0 — revisão para portfólio

- removidas dependências e arquivos gerados que estavam versionados;
- corrigidos erros de lint e espaços Unicode inválidos no JSX;
- centralizada a configuração da URL da API;
- corrigido o fluxo de cadastro, login, endereço e finalização do pedido;
- adicionada transação de banco para salvar endereço e itens do pedido;
- substituída a dependência de hash incompatível por `bcryptjs`;
- removidos endpoints que expunham dados de usuários e pedidos;
- migrados tokens e credenciais para variáveis de ambiente;
- adicionados esquema SQL, documentação de execução e texto para LinkedIn.
