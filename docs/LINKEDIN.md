# Apresentação para o LinkedIn

## Texto sugerido

🚀 Projeto Full Stack — Femanic & Co.

Desenvolvemos um e-commerce de moda do front-end ao back-end, aplicando conceitos de experiência do usuário, integração com API REST e persistência de dados.

A plataforma conta com catálogo de produtos por categoria, cadastro e login com proteção de senha, carrinho com controle de quantidades, registro de endereço e pedidos, além de um bot opcional de atendimento no Telegram.

Principais tecnologias utilizadas:

- React e Vite no front-end;
- Node.js e Express na API;
- MySQL para persistência;
- bcryptjs para proteção das senhas;
- Git e GitHub para versionamento.

Durante o desenvolvimento, trabalhamos organização de componentes, validação de dados, variáveis de ambiente e boas práticas de segurança. O projeto reforçou na prática como as diferentes camadas de uma aplicação web se conectam.

#React #NodeJS #JavaScript #MySQL #FullStack #DesenvolvimentoWeb #GitHub
